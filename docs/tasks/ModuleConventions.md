# ModuleConventions

## Synopsis

Runs module convention validation.

## Description

Runs validation tasks that check module manifest, exported functions,
naming, TODO comments, and function help.

## Includes

- `Manifest`
- `PublicFunctions`
- `Naming`
- `ToDo`
- `Help`

## Run

```powershell
Invoke-Plumber -Task ModuleConventions
```
